# Retail Sales Analytics Dashboard

## Overview

An Excel-based retail sales analytics dashboard designed to analyze sales performance, order trends, customer demographics, order status, geographic performance, and sales channels.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Data Analysis
- Dashboard Design

## Key Metrics

| Metric | Value |
|---|---:|
| Total Sales | ₹21.18M |
| Total Orders | 31,047 |
| AOV | ₹682 |
| Delivery Rate | 92% |

## Key Insights

- Women contributed 64% of sales.
- Amazon accounted for 35% of orders.
- 92% of orders were delivered.
- Maharashtra recorded the highest sales among the top 5 states.
- March recorded the highest monthly sales in the dashboard.
